# Narration Pattern

Use this pattern for AI plus traditional-tool tutorials.

1. Hook: name the tool pair and show the payoff.
2. Context: explain why this workflow matters for repeated work.
3. Method: describe how AI turns the requirement into steps/scripts.
4. Tool action: describe the traditional software being controlled.
5. Result: point out saved files, recording, subtitles, or validation.
6. Takeaway: tell viewers how to reproduce the idea in their own workflow.

For screen recordings, do not narrate every mouse movement. Compress slow drawing or waiting time into concise explanation.
